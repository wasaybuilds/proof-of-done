# Security Policy

## Reporting a vulnerability
Please **do not** open a public issue. Use GitHub's private vulnerability reporting ("Report a vulnerability" under the Security tab).

We aim to acknowledge reports within 3 business days.

## Scope
Of particular interest:
- Ways an agent could bypass verification (e.g. altering policy, faking test results, forging receipts).
- Receipt signature or hash weaknesses.
- The test re-runner escaping its isolated worktree.
